# Self-made-els-latex-template

A two-column LaTeX template based on Elsevier's official `els-cas-templates`, with a central settings block, double-blind mode, and one-click builds for multiple outputs.

## Project structure

```text
.
├── cas-dc-template-main.tex   # Compilation entry; manuscript settings at the top
├── 0.Highlights.tex          # Highlights
├── 1.Author.tex              # Authors, emails, affiliations, and CRediT
├── 2.Abstract.tex            # Text abstract
├── 3.MainText.tex            # Main text
├── cas-refs.bib              # References
├── cas-dc.cls                # Two-column document class
├── cas-common.sty            # CAS formatting package
├── cas-model2-names.bst      # Optional bibliography style
├── compile_all.command      # macOS one-click build
├── compile_all.bat           # Windows one-click build
├── clean_latex.bat           # Windows build-cache cleanup
├── .latexmkrc                # latexmk configuration
├── texfiles/                 # Local settings, ORCID enhancement, and author export
├── example-images/           # Example figures
├── thumbnails/               # CAS contact and social icons
└── doc/                      # Official template guide
```

## Prepare your manuscript

Edit the settings block at the top of `cas-dc-template-main.tex`:

| Setting | Purpose |
|---|---|
| `\PaperTitle` | Paper title |
| `\PaperShortTitle` | Running title |
| `\PaperShortAuthors` | Running author list |
| `\PaperKeywords` | Keywords separated by `\sep` |
| `\PaperFunding` | Funding statement; leave `{}` empty if not applicable |
| `\PaperGraphicalAbstract` | Graphical abstract filename |
| `\PaperOutput` | Output content, listed below |

Enter detailed author information, the abstract, Highlights, and main text in their respective files. Place your figures beside the main file and reference body figures with `\includegraphics{filename}`.

### Double-blind mode and output selection

The default `\BLINDtrue` hides authors, affiliations, emails, funding notes, and CRediT. Change it to `\BLINDfalse` to show author information.

Content is selected independently of anonymity. Set the value in `\newcommand{\PaperOutput}{body}`:

| Value | Content |
|---|---|
| `body` (default) | Main text and text abstract |
| `full` | Main text, text abstract, graphical abstract, and Highlights |
| `graphical` | Graphical abstract only |
| `highlights` | Highlights only |

In non-blind mode, `\ORCIDicontrue` displays ORCID icons and `\ORCIDiconfalse` uses native footnotes. Missing icon dependencies trigger a footnote fallback. Local preferences in `texfiles/els-local.tex` override the top-level ORCID setting. One-click builds create this configuration file automatically.

## Build

### One-click build

| Platform | Requirements | Action |
|---|---|---|
| macOS | MacTeX, Python 3.8+ | Double-click `compile_all.command` |
| Windows | pdfLaTeX, BibTeX, Windows PowerShell | Double-click `compile_all.bat` |

Runtime verification is complete on both platforms. A one-click build saves five PDFs, a Highlights Word document, and an author TXT file in the project directory.

If the macOS launcher cannot run directly, use Terminal:

```bash
bash compile_all.command
```

### Editor or command line

Select pdfLaTeX in your editor and compile the main file. With latexmk:

```bash
# Generate one PDF using the main file's settings
latexmk -pdf cas-dc-template-main.tex

# Generate only the double-blind manuscript
latexmk -pdf cas-dc-template-main-blind.tex
```

Build all five PDFs from the command line:

```bash
# macOS / Linux
ELS_BUILD_ALL=1 latexmk -pdf cas-dc-template-main.tex
```

```bat
:: Windows CMD
set ELS_BUILD_ALL=1
latexmk -pdf cas-dc-template-main.tex
set ELS_BUILD_ALL=
```

```powershell
# Windows PowerShell
$env:ELS_BUILD_ALL = '1'
latexmk -pdf cas-dc-template-main.tex
Remove-Item Env:ELS_BUILD_ALL
```

Keep exactly one main file ending in `-main.tex` in the project directory. Variant `.tex` entries generated by latexmk need no editing and can be regenerated after deletion.

## Outputs

`{base}` is the main filename without `.tex`.

| File | Content |
|---|---|
| `{base}.pdf` | Direct main-file output, controlled by the settings block |
| `{base}-full.pdf` | Full manuscript with authors, graphical abstract, and Highlights |
| `{base}-without-abstract.pdf` | Manuscript with authors and **text abstract**, without graphical abstract or Highlights |
| `{base}-blind.pdf` | Double-blind manuscript with text abstract |
| `{base}-graphical-abstract.pdf` | Standalone graphical abstract |
| `{base}-highlights.pdf` | Standalone Highlights |
| `{base}-highlights.docx` | Editable Highlights Word document, generated by one-click builds |
| `{base}-authors.txt` | Author details for submission forms, generated by one-click builds |

One-click builds produce the variants above regardless of the main file's default switches. Highlights PDF and Word share `0.Highlights.tex`; Word reads its title from `\PaperTitle`. Write one `\item` per line. Word supports simple text formatting; check the conversion of complex equations and LaTeX commands.

One-click builds and latexmk all-version or explicit variant builds clear identifying and compilation metadata from outputs. Successful builds remove intermediate files; failed builds retain logs. Check `*-run.log` and `*-bibtex.log` when troubleshooting.

## Submission preparation

Use `\BLINDtrue` and `\PaperOutput` set to `body` for a double-blind manuscript. For source submission, prepare:

- `cas-dc-template-main.tex`, `2.Abstract.tex`, and `3.MainText.tex`.
- `cas-refs.bib` and the figures referenced by the main text.
- Document classes, packages, and bibliography styles required by the journal system. The active bibliography style is `elsarticle-num.bst`.

For a manuscript showing authors, add `1.Author.tex`. A full manuscript also needs `0.Highlights.tex` and your graphical abstract. Submit standalone graphical abstract and Highlights attachments as required by the journal. For PDF-only double-blind submission, use `*-blind.pdf`.

Keep `texfiles/`, `example-images/`, build scripts, generated variant entries, logs, and author TXT files out of submission attachments. Place your own figures beside the source files, replace example figures, and review the PDF produced by the submission system.

## Typesetting tips

- Use `\cref{}` for references that include the figure, table, or equation type, and `\cite{}` for citations.
- `3.MainText.tex` includes figure, table, and `algorithm2e` examples.
- Enter author contributions with `\credit{...}` in `1.Author.tex`.
