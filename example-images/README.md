# 模板示例图片 / Template example images

`simple-png.png` 是示例正文插图，`ga-figure.pdf` 是示例图像摘要。仅供模板预览和测试，不是使用者的论文素材。不要把本目录当作正式稿件附件上传。

正式写作时把自己的图片放在主文件所在目录，并将正文/图像摘要的 `\includegraphics{...}` 文件名改为自己的素材。模板先查找根目录，再查找本示例目录，投稿时省略本目录仍可读取根目录中的真实图片，无需为投稿重新修改路径。

若仅测试模板示例在投稿系统中的编译，可把实际引用的示例图片单独复制到与 TeX 文件相同的目录；双盲正文只需要正文 PNG，不需要 GA。

These are demonstration assets, not the user's manuscript figures. Do not upload this folder with a real submission. Put your own images beside the main TeX file and update the figure filenames while writing. Root images are searched before this example folder, so the journal can compile your manuscript without the example folder or submission-time path edits.
